# 🏛️ mishkaah/.github

This repository contains the global organization profile, shared governance workflows, brand assets, and contribution standards for the **Mishkaah (مِشْكَاة)** ecosystem on GitHub.

The organization profile rendered at [`https://github.com/mishkaah`](https://github.com/mishkaah) is located in [`profile/README.md`](./profile/README.md).

---

## 📂 Repository Contents
- **`profile/README.md`**: The official bilingual (Arabic & English) Organization Home Page.
- **`profile/assets/`**: High-resolution brand assets, banners, and app icon showcase boards for the home page.
- **`.github/workflows/`**: Shared CI/CD reusable workflows, security policy enforcement, and issue/PR templates.

For complete visual assets and design tokens, see [**`mishkaah/brand`**](https://github.com/mishkaah/brand).  
For the core engineering codebase, see [**`mishkaah/core`**](https://github.com/mishkaah/core).  
For canonical Islamic data, see [**`mishkaah/corpus`**](https://github.com/mishkaah/corpus).
