## 1. الفلسفة المعمارية لمنظومة مشكاة

صُممت المعمارية التقنية لمنظومة مشكاة لتحقيق أقصى درجات الثبات، والتحقق التشفيري المحكم، وانعدام الأخطاء أثناء التشغيل. إن الهدف الأساسي هو صون التراث الإسلامي الرقمي ليبقى ثابتاً غير قابل للتحريف، مع إتاحة الاستعلام والربط الدلالي السلس عبر مختلف التطبيقات الحديثة.

ترتكز البنية التقنية على ثلاثة محاور رئيسية:
1. **الصرامة البرمجية المطلقة في TypeScript**: انعدام مسارب الهروب البرمجي والاعتماد الكامل على بيئة Bun 1.4.0.
2. **نظام التدقيق الجنائي الطبقي صفر (Layer 0 Meta-Validation)**: يتحقق محرك الاختبار من سلامة أدوات الفحص ذاتها قبل فحص بيانات الحزمة.
3. **الشبكة الدلالية المنفصلة (Stand-Off Graph)**: روابط الأعلام والترجمات العالمية تعمل كطبقات دلالية فوقية لا تغير النص العربي التراثي مطلقاً.

## 3. الصرامة البرمجية ومواثيق الأنواع في TypeScript

تلتزم جميع الأدوات البرمجية والمخططات في `mishkaah/core` بأعلى المعايير الهندسية:

- **بيئة التشغيل**: محرك Bun 1.4.0 (`bun`).
- **المحظورات الصارمة**: يحظر الكود البرمجي استخدام `any`، أو `unknown`، أو `z.any()`، أو `z.unknown()`، أو `.passthrough()`، أو تعليقات الهروب `@ts-ignore` و`@ts-expect-error`.
- **مخططات Zod المغلقة**: ينتهي كل مخطط كائن بأمر `.strict()` لرفض أي مفاتيح عشوائية أو غير معرفة في ملفات JSON.
- **التصنيفات النصية الصريحة**: استخدام اتحادات النصوص الصريحة (`z.enum([...])`) والتعبيرات النمطية المحكمة في فحص المعرفات لضمان عدم قبول أي مدخل مجهول.

## 4. نظام التدقيق الطبقي صفر (التحقق من نزاهة المدقق)

لضمان عدم قيام أي مساهم بإضعاف أو تعطيل أدوات الفحص أثناء التحديثات، تطبق مشكاة **نظام التدقيق الطبقي صفر** (`tools/meta_validator/verify_the_verifier.ts`):

```
┌─────────────────────────────────────────────────────────────┐
│             المستوى 0: التحقق من نزاهة المدقق               │
├─────────────────┬─────────────────┬─────────────────────────┤
│    البوابة 0.1   │    البوابة 0.2   │        البوابة 0.3      │
│ حارس شجرة الرموز │ قفل التشفير الرقمي│ 28 فخ فساد اختباري     │
│ (حظر التساهل)    │ لمطابقة البصمات │ (نسبة رصد 100%)         │
└─────────────────┴─────────────────┴─────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                المستوى 1: بوابات التدقيق الخمس               │
├───────────┬───────────┬───────────┬───────────┬─────────────┤
│  البوابة 1 │  البوابة 2 │  البوابة 3 │  البوابة 4 │   البوابة 5 │
│ الصياغة   │ المخططات  │ المعرفات  │ الشبكة    │ الختم       │
│ والروايات │ القياسية  │ والمفاتيح │ والمصادر  │ القرآني     │
└───────────┴───────────┴───────────┴───────────┴─────────────┘
```

1. **البوابة 0.1: حارس شجرة الرموز (AST Guard)**:
   يمسح جميع ملفات TypeScript عبر واجهة مترجم اللغة البرمجية لرصد وحظر أي استخدام لأنواع متساهلة أو مخططات غير محكمة.
2. **البوابة 0.2: قفل المدقق التشفيري (`validator_lock.json`)**:
   يحتفظ ببصمات SHA-256 لكافة أدوات الفحص والمخططات؛ وأي تغيير غير موثق يمنع إكمال عملية البناء.
3. **البوابة 0.3: جناح أفخاخ الفساد الـ 28 (Poison Canaries)**:
   يتم حقن 28 عينة تالفة ومحرفة اصطناعياً في الذاكرة (كلمات قرآنية محرفة، معرفات مكسورة، مصادر وهمية). ويجب أن يكتشفها المدقق بنسبة **100.0%** كاملة وإلا يفشل النظام فوراً.
4. **البوابة 0.4: حراسة مسارات العمل (CI Workflow Guard)**:
   يفحص ملفات GitHub Actions للتأكد من تشغيل الاختبارات البرمجية دون أعلام تجاهل أو تجاوز للأخطاء.

## 5. المجالات الستة للأعلام والكيانات

تنظم مشكاة جميع الأعلام والمواضع والمفاهيم التاريخية في ستة مجالات رقمية محكمة بمعرفات ثابتة (URNs):

1. **`mishkah:figure:<id>`**: تراجم الأنبياء، والصحابة، ورواة الحديث، والعلماء، وسنوات وفياتهم وعلاقات الإسناد.
2. **`mishkah:place:<id>`**: البلدان والمدن والجبال والأودية التراثية بأسمائها التاريخية وإحداثياتها الجغرافية.
3. **`mishkah:event:<id>`**: الوقائع والغزوات التاريخية والأيام والمواثيق.
4. **`mishkah:term:<id>`**: المصطلحات الاصطلاحية في أصول الفقه، والعقيدة، ومصطلح الحديث، واللغة.
5. **`mishkah:group:<id>`**: القبائل التاريخية، والمدارس العلمية، والمذاهب الفقهية.
6. **`mishkah:object:<id>`**: المقتنيات والآثار التاريخية والمخطوطات المذكورة في كتب السنة والآثار.

## 7. الترجمات الخارجية المنفصلة (Stand-Off Localization)

صُممت ترجمات اللغات العالمية (الإنجليزية، الأردية، الفرنسية، الإندونيسية) لتكون **طبقات منفصلة**:
- يبقى النص العربي التراثي مصوناً لا تعتريه أي مفاتيح أو وسوم أجنبية.
- تحفظ الترجمات في مسارات منفصلة `corpus/translations/{lang}/...`.
- ترتبط كل ترجمة بمعرف URN العربي الأصلي بنسبة 1-إلى-1 عبر حقل `target_urn`.
- يمكن لفرق الترجمة العالمية مراجعة وتنقيح الترجمات دون إحداث أي تعارض في مستودع النصوص العربية الأصلي.

## 8. محرك بناء قواعد SQLite FTS5 للبحث دون اتصال

لتوفير بحث نصي فائق السرعة لتطبيقات الويب والهواتف دون الحاجة إلى اتصال بالإنترنت، يجمع مستودع `mishkaah/core` الحزمة التراثية البالغة 935 ملفاً في قاعدة بيانات SQLite مدمجة ذاتية الاحتواء:
- **البحث النصي الكامل (FTS5)**: وحدة تجريد عربية مخصصة تزيل التشكيل وتوحد كتابة الهمزات وتبني روابط الجذور المعجمية.
- **الفهرسة التراكمية (Trigram & Prefix)**: تمكن المستخدم من البحث اللحظي في أكثر من 62,000 حديث و37,000 فقرة تفسيرية في أقل من 15 مللي ثانية على الهواتف الذكية.
- **استقلالية تامة عن الشبكة**: تجربة قراءة وبحث كاملة للمستخدمين في كافة البيئات.

## 9. دليل البدء السريع للمهندسين والمطورين

لتشغيل منظومة التدقيق والاستوديو محلياً:

```bash
# استنساخ المستودع الأساسي
git clone https://github.com/mishkaah/core.git
cd core

# تهيئة المستودع الفرعي للحزمة
git submodule update --init --recursive

# تثبيت الحزم البرمجية عبر Bun
bun install

# فحص صحة الأنواع في TypeScript
bun x tsc --noEmit

# تشغيل نظام التدقيق الطبقي صفر
bun test tools/meta_validator/verify_the_verifier.test.ts

# تدقيق روابط التوثيق ومطابقة لغة الملفات
bun run tools/validators/verify_markdown_links.ts

# تشغيل مدقق الحزمة الشامل ذي البوابات الخمس
bun run tools/validators/verify_corpus.ts

# إطلاق استوديو التحرير المرئي
bun run studio
```
