### بنية المشروع وتوزيع المستودعات

ينقسم مشروع مشكاة إلى ستة مستودعات متخصصة:

- **`mishkaah/corpus`**: ملفات البيانات بصيغة JSON للنصوص العربية (القرآن، التفاسير، الحديث، المتون، الأذكار، المعاجم، التراجم) وترجماتها إلى اللغات العالمية.
- **`mishkaah/core`**: أدوات وسكربتات المشروع المكتوبة بـ TypeScript لفحص البيانات، وبناء قاعدة بيانات البحث السريع، واستوديو التحرير المرئي.
- **`mishkaah/app`**: تطبيقات القراءة والبحث للويب والهواتف مع دعم كامل للعمل دون اتصال بالإنترنت.
- **`mishkaah/sdk`**: مكتبة برمجية (`@mishkaah/sdk`) للتعامل مع معرّفات النصوص (URNs) وتحليل الروابط التفاعلية.
- **`mishkaah/brand`**: الشعارات الخطية وحزم أيقونات التطبيقات للهواتف والألوان والخطوط.
- **`mishkaah/.github`**: الأدلة العامة، والتعريف بالمشروع، ونماذج الإبلاغ والتواصل.

### معايير الجودة والفحص البرمجي

تعمل جميع أدوات وسكربتات `mishkaah/core` على بيئة **Bun 1.4.0** بكود TypeScript صارم:
- **منع الأنواع المتساهلة**: يحظر الكود استخدام `any` أو `unknown` أو `.passthrough()`.
- **مخططات Zod مغلقة**: ينتهي كل مخطط بأمر `.strict()` لرفض أي حقول إضافية غير محددة بدقة.
- **اختبار أداة الفحص على نفسها**: تجري أداة الفحص 28 اختبار خطأ مقصود في كل عملية بناء، للتأكد من يقظتها وصحة أدائها.
- **قفل القواعد تشفيرياً**: تُحفظ بصمات SHA-256 لجميع المخططات في ملف `validator_lock.json` لمنع تعديل القواعد خلسة.

### هيكل البيانات والربط الداخلي

- **معرفات ثابتة (URNs)**: يحظى كل كتاب أو آية أو راوٍ أو مصطلح بمعرف دائم (مثل: `mishkah:figure:umar_ibn_al_khattab`).
- **نقاء النص العربي**: توضع النصوص العربية كاملة الضبط في مجلد `corpus/`، بينما تُحفظ الترجمات في ملفات منفصلة في `corpus/translations/` لترتبط 1-إلى-1 بالمعرف الأصلي دون التأثير على النص العربي.
- **المعاجم ثلاثية الطبقات**: ترتبط المفردة من معجم الجذور (*لسان العرب*) إلى معجم غريب القرآن (*الأصفهاني*) إلى معجم المصطلحات (*التعريفات*).
- **البحث دون اتصال**: تُجمع ملفات الحزمة في قاعدة بيانات SQLite مدمجة واحدة مزودة بمحرك بحث نصي (FTS5) وتطبيع خاص للحروف العربية يتيح البحث الفوري في أجزاء من الثانية دون حاجة للإنترنت.

### تشغيل الأدوات محلياً

لتشغيل أدوات الفحص أو فتح الاستوديو على جهازك:

```bash
# استنساخ المستودع الأساسي مع المجلدات الفرعية
git clone --recurse-submodules https://github.com/mishkaah/core.git
cd core

# تثبيت الحزم البرمجية
bun install

# فحص صحة الأنواع
bun x tsc --noEmit

# تشغيل حزمة الاختبارات وفحص الأداة لنفسها
bun test tools/meta_validator/verify_the_verifier.test.ts

# تشغيل مدقق الحزمة الشامل
bun run tools/validators/verify_corpus.ts

# فتح استوديو التحرير المرئي
bun run studio
```
